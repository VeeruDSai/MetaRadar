# Plan 12-03: Approval Request Workflow - Frontend UI

**Phase:** Phase 12 - Hackathon MVP
**Wave:** 3 of 4 - P1 (Cross-Functional Decision Chain UI)

---

## 1. Objective

Build the frontend components that make the approval workflow visible and interactive for judges:

1. ApprovalRequestModal - functional team member submits approval request
2. PendingApprovalsPanel - Leadership sees and acts on pending requests
3. SignalCard approval badge - shows PENDING/APPROVED/REJECTED status
4. Dashboard hero card - Leadership sees pending approvals count
5. Functions workspace integration

---

## 2. Implementation Specifications

### A. [NEW] frontend/components/signals/ApprovalRequestModal.tsx

Modal component opened from SignalCard "Request Approval" button.

Props:
  signal: Signal
  onClose: () => void
  onSubmitted: () => void

UI:
  - Signal title + priority badge at top
  - Textarea: "Why does this need Leadership approval?" (min 20 chars)
  - Urgency selector: CRITICAL / HIGH
  - Submit button (disabled while loading)
  - On submit: calls POST /api/v1/signals/{id}/request-approval
  - On success: toast "Approval requested from Leadership" + onSubmitted() + close

### B. [NEW] frontend/components/signals/PendingApprovalsPanel.tsx

Leadership-only panel for the Functions workspace.

- Fetches GET /api/v1/signals/pending-approvals on mount
- Shows count badge "N Pending Approvals"
- List of approval request cards showing:
    - Signal title + priority chip + source
    - Requesting function + display name
    - Request note (expandable)
    - Requested at timestamp
    - Two buttons: [Approve] [Reject]
    - Decision note textarea (required for Reject, optional for Approve)
- On Approve/Reject: calls POST /api/v1/signals/{id}/resolve-approval
- On success: removes from list + shows "Decision recorded" confirmation

Visibility: Only rendered when role === 'LEADERSHIP' or role === 'ADMIN'

### C. [MODIFY] frontend/components/signals/SignalCard.tsx

Add approval status section below the existing action buttons:

If signal.approval_status === 'PENDING':
  Show amber badge: "Awaiting Leadership Approval" + small info icon

If signal.approval_status === 'APPROVED':
  Show green badge: "Approved by Leadership" + resolution_note if present

If signal.approval_status === 'REJECTED':
  Show red badge: "Returned by Leadership" + resolution_note

For non-leadership roles on HIGH/CRITICAL signals with no pending approval:
  Show "Request Leadership Approval" button (opens ApprovalRequestModal)

For LEADERSHIP/ADMIN roles:
  Show "Review Approvals" link to Functions workspace (no request button)

### D. [MODIFY] frontend/components/metaradar.tsx - DashboardPage

For LEADERSHIP/ADMIN role: Add an alert card in the hero section:
  "N Signals Pending Your Approval" with a link to /functions
  Fetches count from GET /api/v1/signals/pending-approvals (returns [] for non-leadership)

### E. [MODIFY] frontend/components/functions/FunctionsWorkspace.tsx

Add PendingApprovalsPanel above the existing role cards grid.
Only rendered for LEADERSHIP/ADMIN roles (check via useAuth).

### F. [MODIFY] frontend/lib/api.ts

Add API functions:

  getPendingApprovals(): Promise<ApprovalRequest[]>
  resolveSignalApproval(signalId: string, status: 'APPROVED' | 'REJECTED', note?: string): Promise<ApprovalRequest>

### G. [MODIFY] frontend/types/api.ts

Add ApprovalRequest type:

  requested_by_role: string

  status: 'PENDING' | 'APPROVED' | 'REJECTED'
  resolved_by_role: string | null
  resolved_by_display_name: string | null

  resolved_at: string | null

Extend Signal type:
  approval_status?: 'PENDING' | 'APPROVED' | 'REJECTED' | null

## 3. UX Flow for Hackathon Demo

Judge walks through this 3-minute sub-scenario:

1. Log in as Medical Affairs -> see CRITICAL signal in Signals tab
2. Open signal card -> click "Request Leadership Approval"
3. Type rationale: "This adverse event signal requires immediate strategic guidance on clinical hold decision"
4. Click Submit -> amber "Awaiting Leadership Approval" badge appears on signal card
5. Log out -> log in as Leadership
6. Dashboard hero card shows: "1 Signal Pending Your Approval"
7. Navigate to Functions -> PendingApprovalsPanel visible at top
8. See the Medical Affairs request with rationale
9. Click Approve + note: "Authorized to proceed with safety review. Schedule DSMB within 7 days."
10. Log out -> log in as Medical Affairs
11. Signal card now shows: "Approved by Leadership: Authorized to proceed with safety review..."
