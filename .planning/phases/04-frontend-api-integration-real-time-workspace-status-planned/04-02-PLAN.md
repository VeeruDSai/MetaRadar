# Plan 04-02: Live API Client, Mapper Module & Polling Hook

## Focus & Scope
Implement the production-grade Next.js REST client in `frontend/lib/api.ts` connecting to FastAPI backend `/api/v1` routes (`/signals`, `/overview`, `/athena`, `/search`, `/health/ready`, `/health/models`). Implement pure mapping functions (Decisions D-04, D-05) to bridge OpenAPI relational schemas to frontend UI contracts, and build the concurrency-safe, visibility-aware `useLiveData` hook (Decisions D-01, D-02, D-03).

## Tasks
1. **Task 04-02-T1: Build `useLiveData` Hook (`frontend/lib/hooks.ts`)**
   - Implement `useLiveData<T>(fetcher, intervalMs = 30000)` managing `data`, `loading`, `isRefreshing`, `error`, `lastUpdated`, and `refetch`.
   - Add in-flight request guard (`inFlightRef`) to avoid overlapping requests.
   - Add `AbortController` cancellation on unmount and visibility change.
   - Add Page Visibility API integration (`document.visibilityState`) pausing intervals on hidden tabs and immediately refreshing on tab focus.
   - Add Next.js SSR guards (`typeof window !== 'undefined'`).
2. **Task 04-02-T2: Implement Typed REST Client & Pure Mappers (`frontend/lib/api.ts`)**
   - Define `ApiError` class with HTTP status, statusText, message, and `isRetryable`.
   - Implement `apiFetch<T>` helper targeting `process.env.NEXT_PUBLIC_API_URL || 'http://localhost:8000/api/v1'`.
   - Implement pure mappers: `mapSignal`, `mapOverview`, `mapAthenaResponse`, `mapSearchResult`.
   - Export typed public functions: `getOverview`, `getSignals`, `askAthena` (with 500-char input clamping), `searchSignals`, `getHealthReady`, `getHealthModels`.
   - Remove static `@/lib/mock-data` imports completely.
3. **Task 04-02-T3: Type Checking & Linting Gate**
   - Verify 0 TypeScript errors: `node frontend/node_modules/typescript/bin/tsc --project frontend/tsconfig.json --noEmit`.
   - Verify 0 ESLint errors: `npm --prefix frontend run lint`.

## Verification Criteria
- `tsc` and `eslint` pass with 0 errors.
- `useLiveData` handles tab visibility events cleanly without memory leaks.
