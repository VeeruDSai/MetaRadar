# Technology Stack

**Analysis Date:** 2026-08-13

> **Current state:** The repository has moved from specification-only to an **early implementation scaffold**. The backend foundation (FastAPI app, DB models, Alembic migration, LLM provider abstraction, config) and a minimal frontend skeleton (1 page + generated API types) exist. The AI/ML model layer and all external data connectors are **simulated/scaffolded, not wired to real libraries or endpoints** — the Master Plan ([`docs/METARADAR_MASTER_PLAN_v5.0.md`](docs/METARADAR_MASTER_PLAN_v5.0.md)) prescribes the full stack; this document records what is *actually in code* and flags discrepancies.

## AI / ML

**All model execution is currently SIMULATED** — the three provider classes return canned/truncated strings; no model weights are loaded (no `transformers`, `sentence-transformers`, or `spaCy` in `requirements.txt`).

**Provider abstraction ([`backend/app/providers/`](backend/app/providers/)):**
- `base.py` — `LLMProvider` ABC with capability enum (`SUMMARIZE`, `CLASSIFY`, `REASON`, `GENERATE_ACTIONS`, `STRUCTURED_OUTPUT`) and `DataClassification` enum (`PUBLIC`, `SYNTHETIC`, `CONFIDENTIAL`, `INTERNAL`, `PATIENT_IDENTIFIABLE`, `UNKNOWN`)
- `gemma.py` — `GemmaProvider` (model `google/gemma-3-4b-it` from `LOCAL_LLM_MODEL`); **simulated** — hardcoded `what_changed`/`why_it_matters`/`primary_function=METAD_AFFAIRS` output. Declared capabilities: all five
- `grok.py` — `GrokProvider` (model `grok-beta`); **simulated inference** but implements the **real mandatory privacy gate** (`validate_privacy_gate`: only `PUBLIC`/`SYNTHETIC` classifications pass; requires `ENABLE_GROK_FALLBACK=true` + `XAI_API_KEY`)
- `degraded.py` — `DegradedProvider` (named `facebook/bart-large-cnn`); **simulated** — naive text truncation at 300 chars, `mode="degraded_factual"`, `reasoning_available=False`, `actions_available=False`
- `factory.py` — `ProviderFactory.execute_task()` fallback chain: **local Gemma → Grok (if enabled + privacy gate) → BART degraded**. Selection driven by `settings.LLM_PROVIDER` (`local`|`xai`|`auto`)

**LLM/embedding configuration (`.env.example`, `backend/app/core/config.py`):**
- `LLM_PROVIDER=local`, `LOCAL_LLM_MODEL=google/gemma-3-4b-it`, `LLM_DEVICE=auto` (docker-compose overrides `cpu` or `cuda:0`), `LLM_DTYPE=int4`, `MAX_CONTEXT_TOKENS=2048`, `MAX_OUTPUT_TOKENS=512`
- `ENABLE_GROK_FALLBACK=false`, `XAI_API_KEY=` (optional hosted fallback, default off)
- Embedding vars as above

**NLP services:**
- `services/redteam.py` — `RedTeamNLIService`; **mock pairwise contradiction check** (same-asset + different-type rule), in-memory cache, candidate cap 10, HIGH/CRITICAL priority gating. The prescribed `facebook/bart-large-mnli` NLI model is **not implemented**
- `services/deduplication.py` — deterministic fingerprinting (`pmid:`, `nct:`, `reg:`, `hash:sha256` of normalized title|publisher|date|company|asset) + 256-token text chunking for the embedding model's max sequence length
