<objective>
Make every operational read path honest: connector health surfaces real ingestion telemetry with an explicit CONFIGURATION_ERROR state for missing credentials, per-attempt ingestion logs are debuggable and secret-free, confluence eligibility counts distinct independent sources (source_id) with the UI copy matching the backend rule, and every contributing evidence item is individually traceable to its original public source. Remove every remaining fabricated status, score, and source count.

Purpose: Plan 08-01 fixed the provenance read path for signals; this plan fixes the operational read paths (health, registry, observability, ingestion, confluence, overview) that still fabricate values — a 200-on-HEALTHY status, a LIVE status not in the enum, hardcoded latency/score/source-count fallbacks, and a signal_type-based confluence rule that can never fire on live data. D-08-06/07/11/12 require telemetry and semantics that reflect what actually happened, not plausible constants.

Output: CONFIGURATION_ERROR reporting end-to-end (env helper → endpoints → Sources page badge + Settings credential display data), honest telemetry everywhere, per-attempt ingestion logs, confluence semantics on distinct source_ids with traceable per-evidence rows, three new test files, and one edited invariant test.
</objective>
