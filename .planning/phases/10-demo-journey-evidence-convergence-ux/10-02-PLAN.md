## 1. Objective

1. Build `EvidenceConvergenceWidget.tsx` to visually display multi-source convergence (e.g. `3 Authoritative + 1 Discovery`) showing how independent sources confirm the same competitive development.
2. Build `PriorityScoreExplainer.tsx` to break down priority numbers into transparent additive clinical evidence factors (`+30 Phase III Readout`, `+25 Key Competitor Asset`, `+20 Multi-Source Corroboration`, `+15 Tier 1 Authority`).
3. Build `RedTeamCounterFactuals.tsx` ("What Could Invalidate This?") to surface self-challenging Red-Team 19-rule logic directly on the Signal Detail page.
4. Enhance `SignalCard.tsx` and `SignalDetailWorkspace.tsx` with explicit source hierarchy badges (`EVIDENCE PRIMARY`, `VALIDATION`, `DISCOVERY`).
5. Ensure 100% compliance with CSS custom tokens (`scripts/check-banned-classes.mjs`).
