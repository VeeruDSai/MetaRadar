## 1. Objective

Guarantee complete provenance integrity across all 8 supported data connectors:
1. Provenance Taxonomy Definition:
   - `SOURCE_VERIFIED`: Canonical document ID / URL extracted directly from trusted primary/authoritative registries (PubMed, ClinicalTrials.gov, EMA EPAR, FDA Drugs@FDA, BioPharma Dive, Fierce Pharma, ET Pharma).
   - `URL_PRESENT`: Syntactically valid URL present from connector.
   - `SOURCE_UNAVAILABLE`: Upstream aggregator link missing or generic (e.g., generic `newsapi.org` root).
2. NewsAPI Ingestion Fix: Pass through verbatim article `url` to `canonical_url` and assign `SOURCE_VERIFIED` (if valid article URL) or explicit `SOURCE_UNAVAILABLE`.
3. Complete Connector Auditing: Verify that all 8 connectors map canonical URLs and document identifiers correctly:
   - Primary: `pubmed` (PMID), `clinicaltrials` (NCT ID)
   - Validation: `fda` (Application ID/Drug URL), `ema` (EPAR/Press Release URL)
   - Discovery: `biopharmadive`, `fiercepharma`, `etpharma`, `newsapi`
4. UI Truthfulness: Explicit "View Original Source" button for `canonical_url` and "Source Unavailable" badge for `SOURCE_UNAVAILABLE`.

### B. [MODIFY] `backend/app/services/provenance_urls.py`
```python
def resolve_canonical_provenance(
    source_id: Optional[str],
    existing_url: Optional[str],
    external_id: Optional[str],
    pmid: Optional[str],
    nct_id: Optional[str],
    title_or_content: str,
    is_synthetic: bool = False,
    existing_status: Optional[str] = None,
) -> Tuple[Optional[str], str]:
    if is_synthetic:
        return (existing_url, "FIXTURE")

    # If connector already provided a valid verified canonical URL, preserve it
    if existing_url and existing_url.startswith("http") and not existing_url.startswith("https://newsapi.org/"):
        return (existing_url, "SOURCE_VERIFIED")

    # Resolve from authoritative identifiers
    if pmid:
        return (f"https://pubmed.ncbi.nlm.nih.gov/{pmid}/", "SOURCE_VERIFIED")
    if nct_id:
        return (f"https://clinicaltrials.gov/study/{nct_id}", "SOURCE_VERIFIED")

    # Fallback to source unavailable rather than generic search queries
    return (None, "SOURCE_UNAVAILABLE")
```
