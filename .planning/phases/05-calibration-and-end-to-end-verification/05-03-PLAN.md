# Plan 05-03: Minimal Frontend Calibration UI Widget, BEFORE/AFTER Readout & DoD Release Audit

<objective>
Implement the interactive `StakeholderFeedbackWidget` on Q3 role badges in `frontend/components/metaradar.tsx`, integrate client API methods (`submitFeedback`, `recalibrateRole`, `getCalibrationWeights`, `confirmWatchItem`) in `frontend/lib/api.ts`, render a side-by-side BEFORE vs AFTER calibration comparison card with confidence uplift metrics, and perform the complete Definition of Done verification audit with release documentation.
</objective>

<must_haves>

- `StakeholderFeedbackWidget` inside `SignalDrawer` in `frontend/components/metaradar.tsx`:
  - 5-Star interactive rating for Relevance and Urgency.
  - Action Appropriate toggle / checkbox.
  - Comment text input for watch rule extraction.
  - "Submit Feedback" and "Recalibrate Now" trigger buttons with loading states and error handling.
- BEFORE vs AFTER comparison panel rendering:
  - Baseline vs Calibrated priority badges.
  - Baseline vs Calibrated relevance scores with confidence uplift percentage badge.
  - Parsed watch rule suggestion with a "Confirm Watch Item" button.
- Complete execution and pass of all quality gates: `tsc`, `eslint`, `next build`, `pytest -v`, and contract sync.
- Authored release documentation in `docs/release/v5.1_RELEASE_NOTES.md`.
</must_haves>
