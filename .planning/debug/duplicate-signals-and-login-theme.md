# Debug Session: Duplicate Signals & Login Page Theme Mismatch

**Status**: `RESOLVED & VERIFIED`  
**Trigger**: Multiple duplicate test signals visible on `/signals` and Login Page UI not matching MetaRadar theme.

---

## 1. Symptoms & Root Causes

### Issue A: Duplicate Signals in UI
- **Symptom**: Test signals like `Approval Workflow Pipeline Signal 06e07cda` and `Approval Workflow Pipeline Signal 717b187e` appeared in the live UI, alongside repeated template synthetic titles.
- **Root Cause 1**: `tests/test_approval_workflow.py` created test signals in the live PostgreSQL database (`Approval Workflow Pipeline Signal ...`), but `tests/conftest.py` teardown patterns did not include this prefix.
- **Root Cause 2**: `backend/app/data/synthetic_signals.json` contained generic repeating titles generated by an earlier template.
- **Resolution**:
  1. Updated `tests/conftest.py` with `'Approval Workflow Pipeline Signal%'` and `'approval-fp-%'`.
  2. Updated `backend/app/data/synthetic_signals.json` with 24 distinct, authentic clinical-grade signals across ClinicalTrials.gov, PubMed, FDA, EMA, and congresses.
  3. Updated `backend/app/db/seed.py` to purge test artifacts and seed clean landscape records.

### Issue B: Login Page Theme Mismatch
- **Symptom**: `/login` looked like an external third-party template with raw Tailwind slate colors, inconsistent fonts, a generic Lucide radar spinner, and disconnected rainbow pills.
- **Root Cause**: `frontend/app/login/page.tsx` and `ProfileCard.css` were styled with hardcoded Tailwind utility classes (`bg-slate-900`, `border-slate-800`) instead of utilizing MetaRadar's CSS variable design tokens.
- **Resolution**:
  1. Redesigned `frontend/app/login/page.tsx` to use the official `MetaRadarLogo`, CSS design tokens (`var(--surface)`, `var(--surface-elevated)`, `var(--signal)`, `var(--border)`, `var(--muted-foreground)`, `var(--foreground)`), and Plus Jakarta Sans typography.
  2. Redesigned stakeholder persona pills with `.role-pill` styling, status pulse indicators, and active `--border-selected` glow.
  3. Redesigned `frontend/components/auth/ProfileCard.css` with MetaRadar theme gradients, glassmorphism, and holographic tilt lighting.
