# Plan 10-01: BioPharma Dive RSS Connector & Adaptive NewsAPI Quota Governor

**Phase:** Phase 10 — Undeniable Demo Journey, Evidence Convergence, BioPharma Dive & UX Refinement  
**Wave:** 1 of 3  
**Requirements:** REQ-P10-01, REQ-P10-02, REQ-P10-03, REQ-P10-04  

---

## 1. Objective

1. Add `BioPharmaDiveRSSConnector` at `backend/app/connectors/biopharma_dive.py` using standard library `xml.etree.ElementTree` parsing and domain keyword filters, connecting to verified active RSS feed `https://www.biopharmadive.com/feeds/news/`.
2. Upgrade `biopharmadive` from `configured_no_feed` to an active discovery source across `config/haemophilia.yaml`, `backend/app/connectors/__init__.py`, `backend/app/services/scheduler.py`, and `backend/app/api/v1/endpoints/ingestion.py`.
3. Enhance `backend/app/services/scheduler.py` with an adaptive NewsAPI quota governor that throttles interval when `quota_remaining < 40` and pauses automated fetches when `quota_remaining < 15` with status `HEALTHY (QUOTA_PRESERVED)`.
4. Ensure `quota_remaining` is exposed in `GET /api/v1/health/sources` and rendered in the source operations UI.

## 2. File Modifications

### A. [NEW] `backend/app/connectors/biopharma_dive.py`
- Implements `BioPharmaDiveRSSConnector(SourceConnector)`
- `source_id = "biopharmadive"`, `tier = 3`, `freshness_class = "delayed"`
- Feed URL: `https://www.biopharmadive.com/feeds/news/`
- Extracts `<item>`, parses `<title>`, `<link>`, `<description>`, `<pubDate>`
- Applies domain keyword filtering (`haemophilia`, `hemophilia`, `gene therapy`, `clotting factor`, `novo nordisk`, `roche`, `hemlibra`, `emicizumab`, `fitusiran`, `roctavian`, `valoctocogene`)
- Canonical URL validation using `_looks_like_http_url()`

### B. [MODIFY] `backend/app/connectors/__init__.py`
- Export `BioPharmaDiveRSSConnector` and include in `ALL_CONNECTORS` map

### C. [MODIFY] `config/haemophilia.yaml`
- Update `biopharmadive` in `tier_3_discovery` with `status: active` and `feed_url: https://www.biopharmadive.com/feeds/news/`

### D. [MODIFY] `backend/app/services/scheduler.py`
- Add `biopharmadive` to default source schedules (interval: 30 minutes)
- Add adaptive quota governor logic to `_should_run_source()` or `_execute_connector_run()` for `newsapi`

### E. [MODIFY] `backend/app/api/v1/endpoints/ingestion.py`
- Add `"biopharmadive"` to supported connector trigger list

### F. [MODIFY] `tests/test_connector_health.py` & `tests/test_ingestion.py`
