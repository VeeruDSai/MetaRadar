## 2. Architecture Baseline

### Frontend Architecture
- **Framework**: Next.js 16.3.0 (React 19, Turbopack builder)
- **Styling**: Tailwind CSS v4 (`@tailwindcss/postcss`), PostCSS 8, Vanilla CSS (`globals.css`)
- **UI Components**: Radix UI / `@base-ui/react`, Framer Motion 13, Recharts 3, Lucide React icons
- **Strict Quality Gates**: ESLint 10 with native `@next/eslint-plugin-next` flat config (`eslint.config.mjs`), `tsc --noEmit` strict type checking (`typescript: { ignoreBuildErrors: false }`).

### Backend Architecture
- **Framework**: FastAPI 0.115 + Uvicorn + Pydantic v2
- **Database**: PostgreSQL 16 + `pgvector` + `pg_trgm` via Async SQLAlchemy 2.0 & Alembic
- **Cache**: Redis 7 async client
- **AI/LLM Provider Chain**:
  1. Local Gemma 3 4B (Reasoning / Action generation)
  2. Grok API (Hosted fallback gated by `ENABLE_GROK_FALLBACK` & Privacy Gate)
  3. BART-large-CNN (Degraded factual mode, summarization only)

### Security Controls
- **PII/PHI Scrubber**: `PIIPHIScrubber` (`backend/app/services/pii.py`) enforces regex scrubbing for emails, phone numbers, SSNs, MRNs, and patient DOBs before external transmission.
- **Privacy Gate**: `validate_privacy_gate` in `GrokProvider` blocks non-PUBLIC data from sending to external APIs.
- **Red-Team Contradiction Engine**: `RedTeamNLIService` (`backend/app/services/redteam.py`) implements a 19-rule registry (`REDTEAM_RULES` A–S) with priority gating to prevent quadratic computational cost.
