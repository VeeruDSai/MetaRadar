# Plan 05-02: Curated Hemgenix Demo Dataset, node_calibrate Service Wiring & Scripted E2E Scenario Test

<objective>
Assemble the curated synthetic demo dataset for the "Hemgenix 3-Year Durability Shift" competitive intelligence storyline, connect `node_calibrate` to the persistent `StakeholderCalibrationService`, and implement the automated end-to-end scenario test (`tests/test_e2e_calibration_scenario.py`) driving the complete 8-step pipeline arc.
</objective>

<must_haves>
- `data/synthetic_signals.json` contains the curated 3-signal Hemgenix durability story: PubMed scientific publication (HOPE-B 3-year data), CSL Behring commercial press release, and ASH 2026 congress comparative abstract (with mim8/concizumab benchmarking).
- `node_calibrate` in `backend/app/workflows/nodes/calibrate.py` persists weight deltas to `ScoringWeights`, writes versioned history to `CalibrationHistory`, updates `SignalRouting` calibrated columns, and creates confirmed `WatchItem`s.
- `tests/test_e2e_calibration_scenario.py` implements the scripted 8-step scenario arc:
  1. Ingest Hemgenix demo signals.
  2. Run 10-node intelligence pipeline.
  3. Validate confluence detection and baseline routing for Regulatory & Medical Affairs.
  4. Submit simulated persona feedback for Regulatory (`relevance=5`, `urgency=4`, comments indicating upcoming congress data).
  5. Trigger recalibration via `StakeholderCalibrationService`.
  6. Assert BEFORE vs AFTER shift (score uplift e.g., 0.88 -> 0.97, priority promotion to CRITICAL).
  7. Verify deterministic watch-rule suggestion generation and confirmation.
  8. Run follow-up pipeline pass verifying `node_missing_signal` transitions to `new_evidence_detected` or active watching.
</must_haves>
