# MetaRadar v5.1 Release Notes: Intelligence Calibration & Enterprise Decision Loop

## Executive Summary
MetaRadar v5.1 delivers the enterprise **Feedback & Calibration Intelligence Loop**, completing the automated end-to-end clinical intelligence lifecycle. With v5.1, biopharma leadership and functional teams (Regulatory, Medical Affairs, Safety, Market Access, Communications) can actively score signal relevance, trigger bounded mathematical recalibration, trace versioned weight adaptations, and automatically generate keyword-extracted monitoring watch rules.

---

## What's New in v5.1

### 1. Stakeholder Calibration Loop & WORM Feedback Logging
- **WORM Audit Trail**: Feedback submissions are logged to `calibration_feedback` as append-only write-once-read-many records preserving full provenance (`user_id`, timestamp, star ratings 1-5, comments).
- **Bounded Weight Recalibration**: Feedback adjustments are bounded using learning rate $\alpha=0.05$, centering at neutral $3.0$, and strictly clamped between $[0.1, 2.0]$.
- **Semver Weight Versioning**: Recalibration cycles produce immutable `CalibrationHistory` snapshots tagged with incremental semver strings (`v1.0.1`, `v1.1.0`), recording who triggered the run, timestamp, and active weight matrices.
- **Non-Destructive Calibrated Routing**: `SignalRouting` preserves original immutable `baseline_relevance_scores` while computing and persisting live `calibrated_relevance_scores` and suggested actions.

### 2. Heuristic Watch-Rule Extraction & Proactive Monitoring
- **Regex Keyword Pattern Matcher**: Automatically extracts upcoming trigger events and monitoring time windows (30-180 days) across `congress`, `trial`, `durability`, `regulatory`, `safety`, and `competitor` contexts.
- **Watch Rule Confirmation**: Enterprise reviewers can activate extracted rules via `POST /api/v1/watch-items/confirm`, registering active monitoring targets evaluated by `node_missing_signal`.

### 3. Flagship Scripted End-to-End Hemgenix Scenario
- **High-Fidelity Curated Dataset**: `data/synthetic_signals.json` contains a 3-signal Hemgenix durability story spanning PubMed (HOPE-B 3-year trial follow-up), CSL Behring commercial announcement (88% prophylaxis displacement), and ASH 2026 congress comparative abstract (gene therapy vs subcutaneous non-factor bispecifics).
- **Scripted E2E Pipeline Verification**: `tests/test_e2e_calibration_scenario.py` verifies the entire 8-step pipeline arc: ingestion -> validation -> 5D NLP extraction -> ontology mapping -> confluence convergence -> baseline routing -> simulated feedback -> bounded recalibration (0.88 -> 0.97, CRITICAL priority) -> watch rule confirmation -> missing signal evaluation.

### 4. Interactive Frontend Calibration Experience
- **Signal Drawer Rating Widget**: 5-star interactive rating controls for Relevance and Urgency, role selector pills, action appropriateness checkbox, and comment submission.
- **BEFORE vs AFTER Comparison Diff Card**: Visual side-by-side display of Baseline vs Calibrated relevance scores, priority badges, calibrated suggested action text, and confidence uplift badges (`+9.2% Uplift`).
- **Watch Item Action Bar**: Direct one-click confirmation for extracted watch rule suggestions with confirmed badge state.

## API Endpoints Added in v5.1

| Method | Path | Description |
| :--- | :--- | :--- |
| `POST` | `/api/v1/feedback` | Submit 5-star rating and comment feedback for a signal |
| `GET` | `/api/v1/feedback/summary` | Aggregate feedback statistics and approval rates by stakeholder role |
| `POST` | `/api/v1/calibrate` | Execute batch weight recalibration and compute BEFORE/AFTER diffs |
| `GET` | `/api/v1/calibration/weights` | Retrieve current active scoring weights across all roles |
| `POST` | `/api/v1/watch-items/confirm` | Confirm and activate parsed watch rule suggestion |
