<objective>
Deliver end-to-end source provenance for every displayed signal: provider record → connector raw_payload → RawSignalBronze → node_ingest → runner persistence → Signal row → serializer → API → frontend mapper → SignalCard → EvidenceDrawer → source link. Remove every layered fabrication (serializer re-scoring + confidence 0.85, mapper-invented ids/scores/stakeholders, DataModeBadge "Recorded Demo Data", FDA API-URL-as-canonical) and replace them with honest stored values and explicit NOT AVAILABLE / SOURCE URL UNAVAILABLE states.

Purpose: The previous remediation pass (Phase 07) fixed scoring, health telemetry, and basic theme persistence, but provenance still breaks at the bronze→signal hop (connectors never write url/signal_type into raw_payload; runner hardcodes data_mode="live") and multiple layers fabricate values to mask the gaps. This plan fixes provenance at the source and deletes the fabrication layers.
Output: Migration 005, provenance columns on Signal, connector raw_payload provenance keys, honest serializer/mapper, regenerated API contract, EvidenceDrawer with SOURCE PROVENANCE/VERBATIM EVIDENCE/TRACE sections, SignalCard provenance row, TEST FIXTURE/SYNTHETIC badges, and two new test files.
</objective>
